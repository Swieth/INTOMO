# Setup

## Prerequisites

| Requirement | Version / Notes |
|-------------|----------------|
| MATLAB | 2018a or newer |
| NAIF CSPICE toolkit | MATLAB/MEX interface required. Used for coordinate conversions (`cspice_georec`, `cspice_rpd`). |
| MATLAB Aerospace Toolbox | Required for several coordinate transform utilities in `RayTracer/Frgn_Fcn/`. |
| MATLAB Mapping Toolbox | Required for geodetic/cartographic functions. |
| MATLAB Statistics and Machine Learning Toolbox | Required by `deleteStat.m` for pairwise-distance filtering (`pdist`, `squareform`). |

INTOMO does **not** install or manage CSPICE automatically. You must install and compile the MEX interface separately before running any processing.

## Manual path configuration

Before running [`RUNINTOMO.m`](../Tomography/RUNINTOMO.m) you must edit two variables at the top of [`conf.m`](../Tomography/conf.m):

```matlab
% Use forward slashes ('/') on every OS; a trailing slash is required.
% Examples:
%   Linux/macOS : '/home/user/INTOMO/'          '/home/user/INTOMO-output/'
%   Windows     : 'C:/Users/user/INTOMO/'       'D:/INTOMO-output/'
PATH_INSTALL      = '/path/to/INTOMO/';
PATH_EXTERNALSAVE = '/path/to/INTOMO-output/';
```

`PATH_INSTALL` must point to the repository root (the directory that contains both `Tomography/` and `RayTracer/`).

`PATH_EXTERNALSAVE` is an independent directory where the final tomography output (`OUTPUT_TOMO.mat`) and per-epoch Kalman files are written. It does **not** have to be inside the repository.

A project name is also required:

```matlab
PROJECT_NAME = 'your_project_name';
```

This name is used as the sub-folder name for both input data (`Tomography/DATA/<PROJECT_NAME>/`) and the exported results (`PATH_EXTERNALSAVE/<PROJECT_NAME>/`).

## MATLAB path (`addpath`) set by `conf.m`

When `conf.m` runs it calls `addpath` for the following directories so that MATLAB can find all functions:

| Directory | Contents |
|-----------|---------|
| `Tomography/CONF` | Configuration `.mat` file |
| `Tomography/ENGINE` | Core processing functions |
| `Tomography/External` (and sub-folders via `genpath`) | Third-party utilities (loaded with `genpath`) |
| `Tomography/PPROCESS` | Pre-processing utilities |
| `Tomography/READ` | Data readers |
| `Tomography/WRITE` | Output writers (currently empty) |
| `Tomography/VISUAL` | Visualisation (currently empty) |
| `Tomography/DATA` | Top-level data folder |
| `RayTracer/Frgn_Fcn` | Aerospace/geodetic wrappers |
| `RayTracer/Other_Fcn` | Lightweight helpers |
| `RayTracer/Tomo_Fcn` | Ray tracing physics |
| `RayTracer/UndulationFiles` | Undulation data |
| `<pathTOMO>` | Project WORK directory (added dynamically) |
| `<pathORB>` | Orbit data folder (added dynamically) |
| `<pathMETEO>` | Meteorological data folder (added dynamically) |

## Required folder structure

### Static (shipped with the repository)

```
INTOMO/
├── Tomography/
│   ├── CONF/
│   │   ├── stations.txt          ← GNSS receiver coordinates
│   │   ├── undu.mat              ← geoid undulation grid
│   │   └── <PROJECT_NAME>.mat    ← generated by conf.m on first run
│   ├── ENGINE/
│   ├── External/
│   ├── PPROCESS/
│   ├── READ/
│   ├── VISUAL/
│   └── WRITE/
├── RayTracer/
│   ├── Frgn_Fcn/
│   ├── Other_Fcn/
│   ├── Tomo_Fcn/
│   └── UndulationFiles/
├── conf.m
└── RUNINTOMO.m
```

### Per-project data (must be created before running)

```
Tomography/DATA/<PROJECT_NAME>/
├── ATM/       ← ground GNSS ZTD observation files  (*.txt)
├── METEO/     ← ERA5 numerical weather model files (*.nc)
├── ORB/       ← IGS SP3 satellite orbit files      (*.sp3)
├── RO/        ← UCAR/SPIRE RO Level-1b files       (*_nc or *.nc)
└── WORK/      ← working directory (written by INTOMO)
```

The `ATM/` folder is not needed when `switches.solution = 'SYNTHETIC'`.  
The `RO/` folder is not needed when `switches.integrated = 'no'`.  
The `METEO/` folder is only needed when `aprModel = 'ERA5'`; the `'DETER'` option uses internal GPT2/UNB3mm models.

### Export directory (written during processing)

```
PATH_EXTERNALSAVE/<PROJECT_NAME>/
├── OUT/
│   └── OUTPUT_TOMO.mat    ← final refractivity estimates
└── KAL/
    └── kalman_mat_<n>.mat ← per-epoch Kalman diagnostics
```

These sub-directories (`OUT/` and `KAL/`) are created automatically by `conf.m` when it runs, so no manual setup is needed.

## First-run checklist

1. Install MATLAB 2018a or newer with the Aerospace, Mapping, and Statistics and Machine Learning Toolboxes.
2. Install the NAIF CSPICE MEX interface and verify `cspice_georec` is callable.
3. Edit `PATH_INSTALL`, `PATH_EXTERNALSAVE`, and `PROJECT_NAME` in `conf.m`.
4. Create `Tomography/DATA/<PROJECT_NAME>/{ATM,METEO,ORB,RO}` (the `WORK/` sub-directory is created automatically by `conf.m`).
5. The export directories `PATH_EXTERNALSAVE/<PROJECT_NAME>/{OUT,KAL}` are created automatically by `conf.m`.
6. Place all input data (see [04-inputs.md](04-inputs.md)).
7. Configure the domain, time range, and switches in `conf.m` (see [03-configuration.md](03-configuration.md)).
8. Open MATLAB, navigate to `PATH_INSTALL`, and run `RUNINTOMO`.
