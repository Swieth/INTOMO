## Notes on folder status

| Folder | Status | Notes |
|--------|--------|-------|
| `RayTracer/Tomo_Fcn/` | Active | Core 3-D physics; called from `groundRT` and `spaceRT` |
| `RayTracer/Frgn_Fcn/` | Active | Contains `.asv` autosave files that should be removed from version control |
| `RayTracer/Other_Fcn/` | Active | Small helpers |
| `RayTracer/UndulationFiles/` | Active | Loaded by `Undulation.m` |
| `Tomography/ENGINE/` | Active | All functions called during a run |
| `Tomography/READ/` | Active | Data reading at the start of each run |
| `Tomography/PPROCESS/` | Active (partially) | Some functions (`horsmooth1RT`, `var_comp_anRT`, `Adecor`) exist but are not called in the default workflow |
| `Tomography/WRITE/` | Empty | `addpath` is called for it but no functions exist |
| `Tomography/VISUAL/` | Empty | `addpath` is called for it but no functions exist |
| `Tomography/External/` | Active (loaded via `genpath`) | Third-party code; several files are duplicated between `External/` and `PPROCESS/` |
